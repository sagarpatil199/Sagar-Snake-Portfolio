# Sagar Patil — Snake: Career Edition

A portfolio you can play. Steer the snake, eat the 13 career pellets,
and each one unlocks a piece of my résumé. Clear the board to unlock the full résumé
(or skip straight to it).

Plain HTML/CSS/JS with no build step and no dependencies.

## Deploy on GitHub Pages
1. Put these files in the root of your `<username>.github.io` repo:
   `index.html`, `profile.jpg`, `moksha-icon.png`, `rcu-logo.png`
2. Settings → Pages → Deploy from branch → `main` / root → Save
3. Live in about a minute.

## Edit content
All résumé content lives in the `ME` and `ITEMS` objects at the top of the
`<script>` in `index.html`. The game cards and the résumé page are both built from them.
